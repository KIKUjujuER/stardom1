This is a **patch** release on top of the `android-migration-complete`
milestone. The mouse work that closed the Android migration phase — the
**RMB** key on the left pad next to **Tab**, the second-finger right click,
and the INT 33h mouse state in the save file — is what 1.0.0.11 shipped. This
release puts the name and the mark of the project back where they belong and
fixes one small thing about the save states.

* **The app is called WhereQ-DOSBox.** The launcher name, the notification and
  the launcher icons all carry the name and the mark of the project, the way
  they did before. The package is `com.whereq.dosbox` and the download is
  `whereq-dosbox-1.0.0.13.apk`, so the app installs under its own id and can
  be updated in place from the earlier releases.
* **A restored save keeps the time it was made.** Loading a save state
  rewrites the local file, and the launcher read the time off that file — so
  every restored slot claimed to be *"just now"*. The original save time is
  now carried over, and a slot that was made five hours ago still says *five
  hours ago* after it has been restored.
* **The save-state format did not change.** The fix is in the launcher, not in
  the snapshot, so every save state written by the earlier releases loads
  normally — the file layout is the same version 10 as before.

The saves-folder feature from 1.0.0.12 is unchanged: pick a folder on the
phone (**Config → Saves folder**, or the offer that appears after the first
save) and every slot is mirrored there, gzipped, next to the game itself.
Two archives with the same file name are told apart by name — *game* and *game
(2)* — so their saves never end up in the same place.
