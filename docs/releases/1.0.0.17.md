A **maintenance** release: two small things in **Game Mode** that were wrong in
a way only the screen could show, and the **privacy policy**, which now lives
in the repository next to the code and the licences.

* **The remap mode marks the FIRE button too — and you can see it.** While the
  remap mode is on, the buttons that can be remapped get an outline. The FIRE
  button is filled with the same gold as the outline, so the outline was
  invisible and the button looked like any other one. The outline now follows
  the chip it marks: gold on the dark buttons, dark brown on the gold FIRE
  button. The rule is chosen by the luminance of the chip, so an outline is
  never the colour of the button it is drawn on.
* **The D-pad button names the mode you actually have.** The button in the
  bottom row of the left pad cycles the D-pad output between **ARROWS**,
  **NUMPAD** and **WASD**, and it carries the name of the current mode. When
  the app remembered a different mode for that game, the button kept the name
  of the mode the bar had been built with, so it could say *ARROWS* while the
  D-pad was sending *WASD*. The bar is rebuilt when the mode changes, and the
  remembered mode is restored before the gamepad is built.
* **The privacy policy is in the repository.** The app collects no data and
  does not ask for the `INTERNET` permission, so it cannot send anything
  anywhere even if it wanted to. The policy says so, in full, and now it
  lives in the repository as `docs/PRIVACY.md` — next to `COPYING` and
  `NOTICE`, where the whole history of it is public. The README links to it,
  and the launcher's footer opens it next to the link to the licence screen.
* **A comment that had drifted.** The note on the Konami detector said the
  exit code ends in *N/Y*; the buttons are **X** and **Y**, and the sequence
  says so.

The save states, the bundle launcher, the keyboard and the emulator core are
unchanged: **every save state written by the earlier releases loads normally**.
