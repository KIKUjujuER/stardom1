# WhereQ-DOSBox 1.0.0.19 — DOS game responsiveness

This build changes the default DOSBox CPU cycle policy from plain `cycles=auto`
to `cycles=auto 20000 50% limit 50000`.

The intent is to give real-mode games a more generous initial instruction
budget while retaining `core=auto`: protected-mode titles can still switch to
the Android build's dynamic recompiler. The change is aimed at testing slower
in-game UI operations; it is not yet a claim of verified performance on every
device.

The Android touch-to-mouse coordinate mapping is unchanged in this build. It
remains absolute-position input, so touch responsiveness should be compared
separately after installing the new APK.

The CI debug package uses the distinct application ID `com.whereq.dosbox.preview`, so it can be installed alongside the upstream release APK for testing.
